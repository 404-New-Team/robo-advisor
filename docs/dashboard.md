## 페이지 1: 통합 대시보드 (메인)

> 접근 경로: `/` (사이드바 최상단 "Robby")

페이지 진입 시 자동으로 아래 API를 호출합니다.

- 포트폴리오 최적화 (PPO 또는 MVO)
- 리서치 요약 (Agentic RAG, 출처 3개)
- DRL / MVO / 동일가중 백테스트 3종
- 주문 수량 계산

### 상단 지표 (4개 메트릭)

| 메트릭 | 내용 |
|--------|------|
| 기대 수익률 | 포트폴리오 CAGR (연환산) |
| Sharpe Ratio | 위험 대비 수익 |
| 최대 낙폭 (MDD) | 최고점 대비 최대 손실률 |
| 변동성 | 연환산 포트폴리오 표준편차 |

### 상단 차트 2개

- **추천 포트폴리오**: 최적화된 종목별 비중을 도넛 차트로 표시
- **Walk-Forward 성과**: DRL · MVO · 동일가중 3개 전략의 폴드별 수익률 꺾은선 그래프

### 하단 탭 3개

**포트폴리오 탭**
- 종목·비중·섹터 테이블 (비중 progress bar 포함)
- 백테스트 보조 지표: 누적수익률, Sortino, Calmar, 승률
- 주문 수량 계산 테이블 (투자금액 기준 매수 주수·금액)

**리서치 근거 탭**
- Agentic RAG 리서치 요약 텍스트
- 추론 단계 로그 (plan → retrieve → grade → analyze → verify)

**시뮬레이션 탭**
- 현재는 Walk-Forward 백테스트 결과로 대체 표시 (미래 경로 시뮬레이션 API 미구현)

## 페이지 2: 포트폴리오

> 접근 경로: `/Portfolio`

페이지 진입 시 자동으로 포트폴리오 최적화 + 3개 전략 백테스트를 호출합니다.

### 상단 지표

통합 대시보드와 동일한 4개 메트릭 (기대 수익률, Sharpe, MDD, 변동성).

### 추천 비중 / 세부 조정

- **왼쪽**: 종목별 비중 도넛 차트
- **오른쪽**: 비중 직접 수정 가능한 테이블. 각 종목 비중(%)을 0~60% 범위에서 0.5% 단위로 조정 가능. 수정 후 합계가 자동 정규화됨

### 주문 미리보기

조정된 비중과 투자 가능 금액을 기반으로 종목별 매수 금액을 계산해서 표시합니다.

### Walk-Forward 전략 비교

DRL · MVO · 동일가중 3개 전략의 폴드별 수익률을 꺾은선 그래프로 비교합니다.

**실험 설정**: 2017-01-01 ~ 2025-12-31, train=24개월, test=6개월, step=6개월

## 페이지 3: Research Trace

> 접근 경로: `/Research_Trace`

**이 페이지는 버튼을 눌러야 실행됩니다.** 진입 시 자동 호출 없음.

### 실행 방법

1. **대상 종목** 드롭다운에서 분석할 종목 선택 (또는 "전체 포트폴리오")
2. **출처 수** 슬라이더로 참조할 뉴스/문서 수 조정 (3~10개)
3. **리서치 실행** 버튼 클릭 → 결과가 세션에 저장되어 이후 재진입 시에도 유지됨

### 내부 처리 과정 (Agentic RAG)

```
plan → retrieve → grade → (rewrite →) analyze → verify → (correct →) 완료
```

| 단계 | 설명 |
|------|------|
| plan | 포트폴리오 컨텍스트 기반 검색 쿼리 생성 |
| retrieve | ChromaDB 벡터 검색으로 관련 뉴스/공시 문서 수집 |
| grade | 검색 결과 관련도 점수 계산. 낮으면 rewrite로 재시도 |
| analyze | 수집 문서 기반 Claude API로 투자 요약 생성 |
| verify | 답변 품질 검증 (길이, 리스크 태그 반영 여부, LLM 품질 점수) |
| correct | 검증 실패 시 Claude API로 답변 재생성 (최대 2회) |

### 결과 화면

**요약**: 포트폴리오 리스크 요약 + 투자 의견 텍스트

**리스크 이벤트 테이블**

| 컬럼 | 설명 |
|------|------|
| type | 리스크 유형 (규제 / 실적 / 지정학 / 시장변동성 / 유동성) |
| description | 감지 근거 키워드 |
| severity | high / moderate / low |
| 강도 | 0~1 수치 (progress bar) |
| detected_at | 감지 일자 |

**자체 검증**: Self-Correction 횟수 및 추론 단계별 로그 (접이식 패널)

**출처 테이블**: 참조 뉴스/문서 목록 (제목, URL, 발행일, 관련도 점수)

## 페이지 4: SHAP 의사결정 해석

> 접근 경로: `/SHAP_Explain`

페이지 진입 시 선택된 종목에 대해 자동으로 SHAP 계산을 실행합니다.

### 사용 방법

상단 **해석 대상** 드롭다운에서 분석할 종목을 선택하면 자동으로 SHAP 값을 계산합니다.

### 상단 메트릭

| 메트릭 | 설명 |
|--------|------|
| 최종 비중 | 해당 종목에 할당된 포트폴리오 비중 |
| 양의 기여 합 | 비중 확대에 기여한 피처들의 SHAP 합계 |
| 음의 기여 합 | 비중 축소에 기여한 피처들의 SHAP 합계 |

그 아래에 한국어 자연어 설명이 표시됩니다 (예: "AAPL의 비중이 23.4%로 결정된 주요 원인은 AAPL_mom20d(+0.052)입니다").

### 피처별 기여도 차트 (왼쪽)

SHAP 상위 10개 피처를 가로 막대 그래프로 표시합니다. 파란색(확대) / 빨간색(축소).

**피처 종류** (각 종목 × 11개 기술 지표 + 5개 리스크 지표 + 포트폴리오 비중):

| 피처 | 설명 |
|------|------|
| `{ticker}_ret1d/5d/20d` | 1일/5일/20일 수익률 |
| `{ticker}_vol20d` | 20일 변동성 |
| `{ticker}_mom20d` | 20일 모멘텀 |
| `{ticker}_rsi14` | RSI 14일 |
| `{ticker}_macd / macd_signal` | MACD 및 시그널 |
| `{ticker}_bb_upper/lower/position` | 볼린저 밴드 상/하단 및 위치 |
| `regulatory_risk` | 규제 리스크 수준 |
| `earnings_shock` | 실적 충격 수준 |
| `geopolitical_risk` | 지정학 리스크 수준 |
| `market_stress` | 시장 스트레스 수준 |
| `liquidity_risk` | 유동성 리스크 수준 |
| `weight_{ticker}` | 현재 포트폴리오 비중 |

### 전체 종목 중요도 산점도 (오른쪽)

포트폴리오 내 최대 6개 종목에 대해 각각 SHAP을 계산하여, 피처별로 종목 간 기여도를 비교하는 산점도를 그립니다. 점의 크기는 기여도 절댓값 비례.

### 원본 값 테이블

SHAP 상위 10개 피처의 피처명, 기여도 수치, 방향(확대/축소)을 테이블로 표시합니다.

## 페이지 5: ANOVA 성과 검증

> 접근 경로: `/ANOVA_Results`

**이 페이지는 버튼을 눌러야 실행됩니다.** 진입 시 자동 호출 없음.

실험 조건이 고정되어 있습니다: 2017-01-01 ~ 2025-12-31, train=24mo / test=6mo / step=6mo.

### 실행 방법

1. (선택) **실행 설정** 패널에서 유의 수준 α (기본 0.05), 보상 변형 에피소드 수 (기본 20) 조정
2. **ANOVA 검증 실행** 버튼 클릭 → 결과가 세션에 저장됨

### 검증 1 — 보상 함수 변형 비교 (One-way ANOVA)

**가설**: 보상 함수 설계(R1/R2/R3)가 에이전트 학습에 실질적 영향을 주는가?

| 보상 함수 변형 | 설명 |
|----------------|------|
| R1_LOGRET | 로그 수익률 기반 |
| R2_SHARPE | Sharpe Ratio 기반 |
| R3_FULL | 복합 보상 (수익률 + 리스크 패널티) |

**결과 항목**: F-통계량, p-value, η² 효과 크기, 유의 판정, 그룹 통계 표, 평균 막대 그래프.
유의할 경우 Tukey HSD 사후 검정 결과도 표시됩니다.

### 검증 2 — 전략 간 성과 비교 (One-way ANOVA)

**가설**: DRL이 MVO·동일가중 대비 Walk-Forward CAGR에서 통계적으로 유의미한 차이를 보이는가?

| 전략 | 설명 |
|------|------|
| DRL | PPO 강화학습 기반 포트폴리오 최적화 |
| MVO | 평균-분산 최적화 (Max Sharpe) |
| EqualWeight | 동일가중 |

**결과 항목**: 검증 1과 동일한 구성.

### 검증 3 — 시장 국면별 전략 성과 (Two-way ANOVA)

**가설**: 전략(DRL/MVO/EW)과 시장 국면(Bull/Sideways/Bear)의 주효과 및 상호작용이 CAGR에 유의미한 영향을 주는가?

**요인 구성**:
- 요인 A: 전략 (DRL / MVO / EqualWeight)
- 요인 B: 시장 국면 (Bull / Sideways / Bear)

**결과 항목**:
- 주효과/상호작용 요약 테이블 (F, p, Partial η²)
- 전략별 평균 CAGR 막대 그래프
- 시장 국면별 평균 CAGR 막대 그래프 (폴드 수 표시)
- 전략 × 국면 셀 평균 히트맵 (RdYlGn 색상)
- ANOVA 원본 테이블 (SS, df, MS, F, p — 접이식 패널)
